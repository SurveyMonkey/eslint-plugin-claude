# Docs authoring

This skill holds the detail and the reasons for `.claude/rules/path-docs.md` and
`path-docs-adr.md`. Read only the file that the task needs.

- [okf.md](okf.md): the status model, how to record a declined proposal, the shared keys and
  their reference formats, trust (`generated`, `verified`, `sources`), staleness, and bundle
  navigation. Read it before you add trust, staleness or index metadata, or decline a proposal.
- [adr.md](adr.md): how to write Context before the Decision, how to record a declined decision,
  and the ADR pull request checklist. Read it before you write, supersede or decline an ADR.
- [quality.md](quality.md): problem statements, the gap-statement litmus test, and evidence
  standards. Read it before you write an ADR Context, the Why of an issue, or the reasons for a
  rule.
