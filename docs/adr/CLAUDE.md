# ADRs

This directory holds the Architecture Decision Records (convention: `.claude/rules/path-docs-adr.md`,
shared frontmatter in `.claude/rules/path-docs.md`). One file holds one ADR, named
`NNN-descriptive-slug.md`, with the sections Context, Decision and Consequences. Status is in the
frontmatter, not in a body heading. `index.md` lists the ADRs. Add the row of a new ADR in the
same pull request.
